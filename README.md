# Freecity

Maquette 3D inspirée de l'univers du film *Free Guy* : une ville stylisée, des PNJ avec lunettes et des joueurs distingués par leur couleur.

## Démarrer

Ouvrez `src/index.html` dans un navigateur moderne, ou lancez un petit serveur local :

```bash
cd /workspace/Freecity
python -m http.server 5173 --directory src
```

Puis ouvrez `http://localhost:5173`.

## Ajuster la scène

Utilisez les curseurs pour ajuster la densité de la ville, le nombre de PNJ et de joueurs. Choisissez votre personnage (style + lunettes) puis cliquez sur **Reconstruire la ville**. L'encadré *Aperçu visuel* montre des miniatures pour illustrer la ville, les PNJ et le joueur.
